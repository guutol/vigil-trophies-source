# Vigil Agent v0.1.0-beta.10

## English

- Adds **Shadow of the Colossus PC by AjncSystem** (`sotc-log`, beta). Finds the launcher's configured user folder, portable package or running port automatically, including custom saves folders and the first run before a log exists. Folders you stopped watching stay stopped.
- Reads `Runtime: trophy N unlocked` from `last_run.log`. The game and set come from your dump's `param.sfo` / `npbind.dat`; unidentified folders send nothing. Shadow, Bloodborne and God of War keep separate identities, queues and duplicate detection.
- The website catalog includes all 38 trophies of `NPWR13427_00` / `CUSA08809`, English and Brazilian Portuguese texts and trophy images. Unlocks count as **Played on: PC port**.
- Keep Vigil running while playing. Turn **off** the port's "close launcher when playing" option or use its `--play` shortcut, so it writes the log. Rewritten past logs cannot be recovered. Trophy dates are the time Vigil read them. Direct script runs without a captured `last_run.log` are not supported.
- Automated checks cover discovery, missing/wrong identity, partial and rewritten logs, duplicate/restart handling, offline queue, API and notifications. A disposable server loaded the real catalog, awarded the computed platinum from synthetic unlocks, and preserved progress after reimport. **Real gameplay still needs a player confirmation.**
- Existing installations can check for updates in the tray menu. Quit the old agent, download the new executable and open it; your Vigil settings and account link are retained. Updates are not installed silently.

## Português

- Adiciona **Shadow of the Colossus PC do AjncSystem** (`sotc-log`, beta). Encontra automaticamente a pasta configurada no launcher, o pacote portátil ou o port em execução, inclusive com saves personalizados e antes do primeiro log. Pastas removidas continuam removidas.
- Lê `Runtime: trophy N unlocked` no `last_run.log`. O jogo e o conjunto vêm do `param.sfo` / `npbind.dat` do seu dump; sem identificação, nada é enviado. Shadow, Bloodborne e God of War ficam separados, sem misturar conquistas.
- O catálogo do site inclui os 38 troféus de `NPWR13427_00` / `CUSA08809`, textos em inglês e português brasileiro e imagens. Desbloqueios contam como **Jogado em: port de PC**.
- Deixe o Vigil aberto enquanto joga. Desligue a opção do port de **fechar o launcher ao jogar**, ou use o atalho `--play`, para que o log seja gravado. Logs antigos sobrescritos não podem ser recuperados. A data é quando o Vigil leu o troféu. Execução direta do script sem capturar `last_run.log` não é suportada.
- Testes automáticos cobrem detecção, identidade ausente/incorreta, linhas incompletas, log reescrito, duplicatas/reinício, fila offline, API e notificações. Um servidor descartável carregou o catálogo real, calculou a platina a partir de desbloqueios sintéticos e preservou o progresso após reimportar. **Falta confirmação numa partida real.**
- Quem já tem o app pode buscar atualizações no menu da bandeja. Feche o agent antigo, baixe o novo executável e abra; a configuração e o vínculo da conta são mantidos. Não há instalação silenciosa.

Default service / Serviço padrão: https://vigiltrophies.com
