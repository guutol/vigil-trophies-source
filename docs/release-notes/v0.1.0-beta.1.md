## O que esta beta faz

- **App de bandeja para Windows** (`vigil-agent-tray.exe`): ícone perto do relógio; vincula o PC pelo
  navegador com um código curto; encontra as fontes e pergunta uma vez se pode acompanhá-las; envia os
  troféus novos e mostra uma notificação; pausar/retomar; iniciar com o Windows (só o seu usuário, sem
  admin); idioma pt-BR ou inglês.
- **Fontes**: bbport oficial (log do launcher, sem patch), bbport com o patch do Vigil, RPCS3 (beta) e
  shadPS4 (beta). O agent **só lê** essas pastas; nunca escreve, move ou apaga nada nelas.
- **Sem conexão, sem perda**: se o servidor não responde, os troféus ficam na fila (`%AppData%\vigil`),
  o menu mostra "Sem conexão com o servidor: N na fila, tentando de novo" e o envio é retomado sozinho,
  sem repetir troféus e sem notificações de erro em sequência.
- **Linha de comando** para Windows, Linux e Steam Deck (`vigil-agent-*`): os mesmos recursos, em terminal.

## Instalar e vincular (Windows)

1. Baixe `vigil-agent-tray.exe` e `SHA256SUMS.txt` deste Release e confira o hash (abaixo).
2. Abra o `.exe` (não há instalador; pode mover para qualquer pasta antes).
3. No menu do ícone: **Vincular este PC**. O navegador abre a página com o código; entre na sua conta e
   confirme. *(Só funciona quando o servidor estiver no ar.)*
4. Aceite as fontes encontradas, ou use **Adicionar pasta…**.

Linha de comando: `vigil-agent link`, `vigil-agent sources detect`, `vigil-agent sources add …`,
`vigil-agent run`. Guia completo: `agent/README.md`.

**Outro servidor HTTPS** (sem recompilar): `vigil-agent config server https://seu-servidor` com o
`vigil-agent-windows-amd64.exe` (mesma pasta de configuração do app de bandeja); depois feche e abra o app
e vincule de novo. Trocar de servidor apaga o vínculo local antigo, para o token nunca ir a outro endereço.

**Atualizar**: feche o app pelo menu (**Sair**), substitua o `.exe` no mesmo lugar e abra de novo. Vínculo,
fontes, preferências e a fila ficam em `%AppData%\vigil` e continuam; "Iniciar com o Windows" continua
valendo se o caminho do arquivo for o mesmo.

## Aviso do Windows (SmartScreen)

O executável ainda não tem assinatura de código, então o Windows pode avisar "editor desconhecido".
Antes de abrir, confira o SHA-256 (e a proveniência, quando houver). Não desligue o SmartScreen nem o
antivírus: se, depois de conferir, quiser abrir, use **Mais informações → Executar assim mesmo** só para
este arquivo.

## Conferir os arquivos

Windows (PowerShell):

```powershell
Get-FileHash .\vigil-agent-tray.exe -Algorithm SHA256
Select-String vigil-agent-tray.exe .\SHA256SUMS.txt
```

Linux / Steam Deck: `sha256sum --ignore-missing -c SHA256SUMS.txt`

O repositório ainda é **privado**: só quem tem acesso a ele (dono e colaboradores convidados) consegue ver

## Limitações conhecidas

- Depende do deploy do servidor (`vigiltrophies.com`) para vincular e sincronizar.
- Sem assinatura de código (aviso do SmartScreen); sem atualização automática.
- RPCS3 e shadPS4 testados só com arquivos sintéticos (beta).
- App de bandeja só para Windows; no Linux/Steam Deck, linha de comando.
- Notificações aparecem no monitor principal; jogos em tela cheia exclusiva escondem o card (use janela
  sem borda).
