# Vigil Agent v0.1.0-beta.11

## English

- Hidden trophy popups now show the real name, grade and trophy image after the server confirms the linked account has unlocked that trophy. The public game page still conceals locked spoilers.
- The notification uses an authenticated lookup of persisted ownership. A concealed public-cache entry, a failed earlier lookup or an account switch cannot supply another account's private trophy metadata. Private answers are not cached by the app or shared HTTP caches.
- If metadata or the image is temporarily unavailable, the existing generic fallback remains. This does not remove an achievement, resend it or generate a second popup. Historical imports stay silent; offline delivery and duplicate detection are unchanged.
- Tested with synthetic accounts, catalogs, logs and icons: authenticated ownership, blocked/other-account access, English/Portuguese, old public cache, unavailable metadata, offline queue, history and duplicate/restart handling. No real gameplay or production account was used for these tests.
- Update from the tray menu, quit the old agent and open the new executable. Existing settings and account links are retained. The app does not install updates silently.

## Português

- O popup de troféu oculto agora mostra nome, grau e imagem reais depois que o servidor confirma o desbloqueio na conta vinculada. A página geral do jogo continua ocultando spoilers.
- A notificação usa uma consulta autenticada ao desbloqueio salvo no servidor. Cache público oculto, consulta anterior com falha ou troca de conta não fornecem dados privados de outra conta. Essas respostas não ficam no cache do app nem em caches HTTP compartilhados.
- Se os dados ou a imagem estiverem temporariamente indisponíveis, permanece o fallback genérico. Isso não apaga a conquista, não a reenvia e não gera um segundo popup. Importações históricas continuam silenciosas; fila offline e deduplicação foram preservadas.
- Testado com contas, catálogos, logs e imagens sintéticos: autorização, bloqueados/outra conta, inglês/português, cache público antigo, dados indisponíveis, fila offline, histórico, duplicatas e reinício. Nenhuma partida real ou conta de produção foi usada nos testes.
- Busque a atualização no menu da bandeja, feche o agent antigo e abra o novo executável. A configuração e o vínculo da conta são mantidos. Não há instalação silenciosa.

Default service / Serviço padrão: https://vigiltrophies.com
