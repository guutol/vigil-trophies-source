# Vigil Agent v0.1.0-beta.9

## English

- **God of War III — PC port** ([gow3_pc](https://github.com/FelipePrado0/gow3_pc)), new source `gow3-log` (beta). The agent reads the `last_run.log` the port's launcher writes and sends each `Runtime: trophy N unlocked` line, with the usual notification.
- Automatic detection, without scanning the disk: the port launcher's settings (`game_dir`, `update_dir`, `user_dir`, including a custom or empty saves folder), the `gow3-windows` package in the usual folders, `Games` on each fixed drive, next to the configured game folder, a running port, `GOW3_DATA_DIR` and the Linux AppImage data folder. It is found before the first trophy, and folders you stopped watching stay stopped.
- The trophy set comes from your game folder (`sce_sys/param.sfo` and `npbind.dat`, the update folder first, as the launcher does). If the game cannot be identified, **nothing is sent** and the folder says so; it is never sent as Bloodborne. Bloodborne's own folders work as before, and a God of War III saves folder is no longer taken for bbport.
- The catalog's existing "God of War III Remastered" PS4 set (`NPWR08268_00`) is unchanged; the port's unlocks count there as "Played on: PC port". A dump that names another set waits as pending until that set's catalog is approved. The PS3 game stays a separate set.
- Limitations: keep Vigil open while you play (the launcher rewrites the log each session; an overwritten log cannot be recovered). With the launcher's "close the launcher when playing" option on, the PLAY button writes no log: turn it off, or use the `--play` shortcut. The log has no dates, so the unlock time is when Vigil read it.
- Tested with synthetic files only (fake dumps and set ids): detection, identification, rewritten/truncated logs, partial lines, duplicates, two ports at once, offline queue, API and notification. **Not yet tested in a real God of War III playthrough.**

## Português

- **God of War III — port para PC** ([gow3_pc](https://github.com/FelipePrado0/gow3_pc)), nova fonte `gow3-log` (beta). O agent lê o `last_run.log` que o launcher do port grava e envia cada linha `Runtime: trophy N unlocked`, com a notificação de sempre.
- Detecção automática, sem varrer o disco: configurações do launcher do port (`game_dir`, `update_dir`, `user_dir`, inclusive pasta de saves personalizada ou vazia), o pacote `gow3-windows` nas pastas de sempre, `Games` de cada disco fixo, ao lado da pasta do jogo configurada, um port em execução, `GOW3_DATA_DIR` e a pasta de dados do AppImage no Linux. É encontrado antes do primeiro troféu, e pastas que você parou de acompanhar continuam paradas.
- O conjunto de troféus vem da pasta do seu jogo (`sce_sys/param.sfo` e `npbind.dat`, a pasta de update primeiro, como o launcher faz). Se o jogo não for identificado, **nada é enviado** e a pasta avisa; nunca é enviado como Bloodborne. As pastas do Bloodborne funcionam como antes, e a pasta de saves do God of War III não é mais confundida com o bbport.
- O conjunto de PS4 "God of War III Remastered" que já está no catálogo (`NPWR08268_00`) não mudou; os desbloqueios do port contam nele como "Jogado em: port de PC". Um dump que indique outro conjunto fica pendente até o catálogo desse conjunto ser aprovado. O jogo de PS3 continua sendo outro conjunto.
- Limitações: deixe o Vigil aberto enquanto joga (o launcher reescreve o log a cada sessão; log sobrescrito não tem como ser recuperado). Com a opção do launcher "fechar o launcher ao jogar" ligada, o botão JOGAR não grava log: desligue a opção ou use o atalho `--play`. O log não tem datas, então a hora do desbloqueio é a hora em que o Vigil leu.
- Testado só com arquivos sintéticos (dumps e conjuntos falsos): detecção, identificação, log reescrito/encurtado, linha incompleta, duplicatas, dois ports ao mesmo tempo, fila offline, API e notificação. **Ainda não testado numa partida real de God of War III.**

Default service / Serviço padrão: https://vigiltrophies.com
