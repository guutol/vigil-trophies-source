# Vigil Agent v0.1.0-beta.8

## English

- Blue Vigil tray menu with line icons, clearer grouping, readable folder paths and keyboard focus. Windows still handles menu tracking, submenus, scrolling and dismissal through its documented owner-draw menu API; no embedded browser or new runtime.
- **Manage folders**: open a watched folder, **Stop watching** with confirmation, and **Watch again** from the stopped-folders list. Deliberately removed folders are remembered and not offered again by detection.
- Removal changes only Vigil configuration. Game files, saves, account link, synchronized achievements and queued events are preserved. Queued events still send after removing the last folder.
- **Use system menu** restores the standard Windows menu. High contrast and the Windows screen-reader setting automatically use the standard menu. Text remains available through the native menu API.
- Includes beta.7 update notices and the beta.6 bbport trophy journal reader. Close the old app and open this download; keep your existing configuration.
- Tested: agent tests/vet, actual Win32 menu construction and keyboard selection/submenu/Escape with a synthetic hidden owner, renderer at 100/125/150/200%, EN/PT previews, folder removal/restoration/restart and queue preservation. Physical multi-monitor layouts and individual screen readers still need user validation.

## Português

- Menu azul do Vigil com ícones, grupos claros, caminhos de pastas legíveis e foco pelo teclado. O próprio Windows continua controlando submenus, rolagem e fechamento por sua API documentada de desenho de menus; sem navegador embutido ou novo runtime.
- **Gerenciar pastas** permite abrir a pasta, **Parar de acompanhar** com confirmação e **Voltar a acompanhar** pela lista de pastas removidas. A detecção respeita a remoção entre reinícios.
- A remoção altera apenas a configuração do Vigil. Arquivos do jogo, saves, vínculo, conquistas sincronizadas e eventos na fila permanecem. A fila continua sendo enviada mesmo após remover a última pasta.
- **Usar menu do sistema** recupera o menu padrão. Alto contraste e a opção de leitor de tela do Windows ativam essa alternativa automaticamente. Os textos permanecem disponíveis pela API nativa de menus.
- Mantém os avisos de atualização da beta.7 e o leitor de trophies.log da beta.6. Feche o app antigo e abra o novo download, mantendo sua configuração.
- Validação: testes/vet do agent, menu Win32 real com teclado/submenu/Escape em janela sintética, renderer em 100/125/150/200%, prévias EN/PT, remoção/reativação/reinício e preservação da fila. Monitores físicos com disposições diferentes e leitores de tela específicos ainda precisam de validação do usuário.

Default service / Serviço padrão: https://vigiltrophies.com
