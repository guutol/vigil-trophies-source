# Vigil Agent v0.1.0-beta.3

Beta para testes / Testing beta.

## Português

- Ícones azuis no Explorer, na bandeja e nos recursos dos executáveis Windows, mantendo o desenho da marca.

- Notificações de troféus em azul-marinho, com texto claro e graus metálicos preservados, acompanhando a nova identidade do site.
- Renderização conferida em português e inglês, nas escalas Windows 100%, 125%, 150% e 200%.
- O app usa os registros de conquistas das pastas que você confirma; envia as conquistas e, para jogos desconhecidos, a lista de troféus. Não modifica os arquivos do jogo.
- Fontes disponíveis: bbport; RPCS3 e shadPS4 em beta. Emuladores foram validados com dados sintéticos; o teste real do dono permanece pendente.
- Servidor padrão: https://vigiltrophies.com, já disponível. Downloads públicos no repositório de distribuição; o código principal continua privado.

Windows: baixe `vigil-agent-tray.exe` e `SHA256SUMS.txt`. Confira `Get-FileHash .\vigil-agent-tray.exe -Algorithm SHA256`. Para atualizar, escolha **Sair** no app, substitua o executável e abra novamente. Configuração, vínculo e fila permanecem em `%AppData%\vigil`. Não há atualização automática.

O executável não tem assinatura de código. Notificações usam o monitor principal e podem ficar ocultas em tela cheia exclusiva. Linux/Steam Deck usam a versão de terminal. Não desative o antivírus ou o SmartScreen.

## English

- Blue Explorer, tray and embedded Windows executable icons, preserving the existing mark.

- Navy blue trophy notifications with light text and distinct metallic grades, matching the site's new identity.
- Rendering checked in English and Portuguese at Windows 100%, 125%, 150% and 200% scaling.
- The app uses achievement records from folders you approve; it sends achievements and, for unknown games, the trophy list. It does not modify game files.
- Available sources: bbport; RPCS3 and shadPS4 in beta. Emulator validation used synthetic data; the owner's real-game test is still pending.
- Default server: https://vigiltrophies.com, already online. Public downloads use the distribution repository; the main source repository remains private.

Windows: download `vigil-agent-tray.exe` and `SHA256SUMS.txt`. Check `Get-FileHash .\vigil-agent-tray.exe -Algorithm SHA256`. To update, choose **Quit**, replace the executable and reopen it. Configuration, linking and queued achievements remain in `%AppData%\vigil`. There is no automatic updater.

Executables are not code-signed. Notifications use the primary monitor and can be hidden by exclusive fullscreen. Linux/Steam Deck use the CLI. Do not disable antivirus or SmartScreen.

Build provenance status is reported by the release workflow below; do not assume an attestation exists.
